# Sistema HUSI

Sistema de Información para el Apoyo a la Gestión de Rotaciones del Hospital Universitario San Ignacio.

## Estructura

- frontend: aplicación web desarrollada en Angular.
- backend: API REST desarrollada en Spring Boot.
- docs: documentación y diagramas del proyecto.
Consulta la [guía de organización del código](docs/organizacion-codigo.md) para ubicar pantallas, formularios, servicios y pruebas.
